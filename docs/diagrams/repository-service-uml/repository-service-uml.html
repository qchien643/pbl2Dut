Repository, service và DI/DIP

Service phụ thuộc IRepository; Repository triển khai hợp đồng và các kho cụ thể kế thừa lại.

Cách đọc: đường đứt, đầu tam giác = triển khai interface; đường liền, đầu tam giác = kế thừa; hình thoi đặc = thành phần do Repository sở hữu. Dependency từ TicketService minh họa riêng kho vé.

ServiceDependency được truyền qua constructor
CatalogServiceIRepository<Film>, IRepository<Auditorium>, IRepository<Seat>, const IRepository<Screening>, IRoomStorage.
ScreeningServiceconst IRepository<Film>, const IRepository<Auditorium>, IRepository<Screening>, const IRepository<Ticket>, Clock.
TicketServiceconst IRepository<Seat>, const IRepository<Screening>, IRepository<Ticket>, Clock.

RoomStorage triển khai IRoomStorage; chỉ add/update phòng cùng bộ ghế như một thao tác RAM, không ghi TXT. FilmRepository, AuditoriumRepository, SeatRepository và ScreeningRepository cũng kế thừa Repository với T tương ứng.

Rút gọn: chỉ vẽ TicketService và TicketRepository làm ví dụ; bỏ constructor/destructor, một số hàm và kiểu tham số để vừa hình. Tất cả sáu hàm interface, override và kiểu const đầy đủ nằm trong header. Không vẽ dependency giữa hai cấu trúc dữ liệu: HashTable giữ T* tới entity trong LinkedList, không sở hữu entity.
